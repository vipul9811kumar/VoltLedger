# @voltledger/rv-calibration

WS-C of `docs/VoltLedger - Build Spec v2.md` — residual-value calibration + market back-test.

## Scope decisions locked before this package was built

- **USD/US stays canonical.** Overrides the build spec's original EUR/EU-market pivot for
  this workstream. See `docs/VoltLedger - Build Spec v2.md` WS-C section for the original
  language; the currency/market pivot part of it does not apply.
- **Manheim-primary.** Data-source research (2026-08-13) found Autovista's EU BEV %RV curves
  real but scattered/subscription-gated, and Manheim/Cox Automotive's aggregate Used Vehicle
  Value Index — including a public EV vs non-EV split added May 2026 — genuinely free,
  ongoing, and USD-native. Given the USD decision, Manheim is the primary back-test anchor;
  Autovista points are secondary/illustrative only. See `data/manheim/DATA_CARD.md` and
  `data/autovista/DATA_CARD.md`.
- **Calibration is report-only, not force-fit.** Running the actual numbers showed this
  model's battery-value-only retention and Autovista's whole-vehicle %RV are not the same
  quantity — closing the gap mechanically would require inflating
  `MARKET_DEPRECIATION_RATE` 3-4x, corrupting a constant that also drives forecast curves,
  second-life valuation, and WS-D's portfolio-sim. Decision confirmed with the user
  2026-08-13: report the gap, don't force-fit it. See `CALIBRATION_NOTE.md` (generated by
  `pnpm rv-calibrate`) for the numbers.

## What's in here

- `data/manheim/`, `data/autovista/` — small, hand-curated, source-cited benchmark datasets.
  No live scraper: the old Autovista24 public site now 301-redirects into JD Power, which
  blocks automated fetching (403); Manheim's granular data is paid-API-gated. Both confirmed
  this session, not assumed. Extending either dataset means manually reading a future
  release and adding a row with its source URL.
- `src/calibrate.ts` — computes each chemistry's implied 3yr battery-value retention and
  compares it to the Autovista band. Does not modify `packages/scoring`'s constants.
- `src/backtest.ts` — a directional (not curve-fit) back-test of a small synthetic cohort's
  modeled RV trend against the real Manheim EV Index over the same calendar window.
- `src/scoring-independence.test.ts` — enforces `packages/scoring` never imports this
  package, mirroring `packages/calibration`'s `holdout-guard.test.ts` and
  `packages/validation`'s `no-synthetic-data.test.ts`.
- `src/run.ts` — `pnpm rv-calibrate` from repo root. Writes `CALIBRATION_NOTE.md` (this
  package) and `docs/validation/RV_MARKET_BACKTEST.md`.

## What this workstream did NOT build (deliberately out of scope)

- The cross-cutting `provenance` enum (`REAL_ANCHORED | SIMULATED_CALIBRATED | ILLUSTRATIVE`)
  threaded through `RiskScore`/`ResidualValueEstimate`/`LtvRecommendation`/`OriginationAudit`,
  and the dashboard "Validation" section rendering WS-B/WS-C/WS-D together — both are WS-G's
  acceptance criteria, not this workstream's.
- A fully Manheim-conversion-calibrated recovery curve for WS-D — blocked by paid-API data
  access, documented as a partial delivery in `docs/validation/RV_MARKET_BACKTEST.md`.
